# front-end-development-portfolio

This is a portfolio to demonstrate knowledge and skill in developing with react, node, and angular

# Github commit message standard

feat: → new component or feature

fix: → bug fix

style: → CSS/theme changes

refactor: → code cleanup

docs: → README or documentation

chore: → config, setup, build tasks

# example commit messages

feat(homepage): add hero section layout
style(theme): apply brand color variables
feat(api): create POST /api/contact endpoint
docs(readme): add deployment instructions

## Contact API

The portfolio includes a Node.js/Express API for handling contact form submissions.
